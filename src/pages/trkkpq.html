About the KPQ leaderboard
  • Kerning PQ rounds from Grind Tracker players with sharing on, and from the site's KPQ timer with sending on. Rounds joined part-way aren't counted.
  • Rush: fastest clear, 1st stage to beating King Slime and leaving the Last stage. The Bonus stage isn't counted.
  • Bonus: rounds that went into the Bonus stage, ranked by EXP + mesos gained that round (1 meso = 1 point, our own weighting). A faster Rush leaves more Bonus time, which shows up as more EXP and mesos. Only the tracker reads EXP, so site-timed rounds are on Rush only.
  • One line per party (same party code) or player (home network). A party's trackers each send the same round; it counts once.
  • Today's runs below the board: every round recorded today (this browser's date), in the order the server received them, each with its time (shown in your time), the day's best highlighted. Rounds from before the server kept times list fastest first. It doesn't follow the filters, so the whole day stays visible when the board is filtered down.
  • The server checks every round: the stage times have to fit in the clear, a clear has to be 1 to 60 minutes (our own bounds), the same round sent twice counts once, and one tracker or browser can send 12 rounds an hour.
  • Names link to the player's classicrank.com profile. Filters are saved in this browser.
