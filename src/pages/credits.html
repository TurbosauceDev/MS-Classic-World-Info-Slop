About this page

Thank you

  • This tool exists because these people dug through the game files, tested in the Closed Online Tests and wrote it all up for free. Go visit their sites.
  • Ranked by how much of this tool relies on them.

Rules this tool follows

  • Every number comes from the game files or one of the sources below. Estimates are marked as estimates on the page.
  • Unofficial fan tool. MapleStory is a trademark of NEXON; all game data and art belong to NEXON.

Data last updated

    Dates are when this site last read each source; for the OSMS export, the date of that export.

    1. OSMS Data Explorer

    core data

    By ohmi69. osmsdataexplorer.com · GitHub

    • The game-file export behind almost every tab (launch export since Oct 6, 2026; Closed Online Test 2 before that): monsters, maps, spawns, portals, quests, items, skills, icons, minimaps and crafting recipes.
    • The client formulas (accuracy, hit chance, damage, defense), the craft-level EXP table and the COT1 → COT2 patch notes.

    2. meowdb (NiaMeowDB)

    guides & mechanics

    meowdb.com/msclassic

    • Class guides, levels 1-30: Beginner, Warrior, Magician, Bowman, Thief. These set the Path Planner's skill and stat order, weapons, gear and training maps.
    • 2nd-job guides, levels 30-70: Fighter, Page, Spearman, Hunter, Crossbowman, Assassin, Bandit, F/P Wizard, I/L Wizard, Cleric.
    • Mechanics: damage formula, attack speed, HP/MP gain, EXP table, spawn engine, best grind maps, class DPS rankings, movement speed, weapon reach, KPQ, glossary, release date / launch scope. These drive the damage model, attack times, HP/MP, the level cap, party bonus and boss timers, and the reference tests.
    • Lists: NPC shops (prices, potion shops, upkeep), weapon and material drops, player-confirmed monster drops and mesos per kill, and citizenship grades and shops.

    3. maplestory.quest

    client data

    Data used with the site owner's permission. Raw COT2 data

    • The raw COT2 client data (monster magic attack, used for the Danger column), and the EXP table and formula checks.
    • Valuable quest rewards worth the detour by Chief Stan, used for the valuable-quest picks.

    4. metaroad.gg

    quest picks

    By Jota. Must-Do Quests & Valuable Rewards

    • Tiers and reasons for the valuable quests in the Quest Database and Path Planner.

    5. maplestory.io

    version check · world map

    maplestory.io

    • Its Classic World API is used to compare client versions, so the numbers here can be checked against the launch client when it appears.
    • World Map tab: the Maple Island and Victoria Island world map pictures and dot positions from its Classic World (Closed Online Test 2) client.

    6. meso.watch

    player-shop prices

    Data used with the site creator's permission. meso.watch

    • Player-shop sale prices (median and middle half of the sales it has seen) on item pages, the Items list, Keep or sell, and Frugal mode's optional Loot price.

    6. Roxie's new player guide

    Maple Island
    • The Maple Island quest order and the beginner's route to level 10, together with meowdb's beginner guide.
