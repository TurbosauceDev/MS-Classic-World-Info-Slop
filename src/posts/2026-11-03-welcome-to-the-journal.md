This is a sample post. It exists so the journal has something to show on day one, and so the format below has a live example to point at. It stays until the first real note replaces it.

## What this section is

A journal for the site: shorter and looser than the changelog. The changelog says what shipped; this is where the why goes.

- What we are building next, and the reason for it
- What broke, what it taught us, and what changed after
- Small wins from players that shaped a decision

## How a post is written

Each post is one plain text file in `src/posts/`, with a small header and a body in basic markdown: **bold**, *italics*, `code`, lists, quotes and links like this one to the [site home](https://maplestory.scumlord.studio/). Posts land in Discord and on the site from the same file.

Game names link themselves, no markup needed: a **Blue Snail**, an **Orange Mushroom**, a pair of **Work Gloves**, the quest **Arwen and the Glass Shoe**, or a skill like **Magic Claw**. Only the first mention links, and only real names from the game files.

> If a name does not turn into a link, it is not spelled the way the game spells it.

## What comes next

Posts will be writable straight from Discord: type a note in the channel, the bridge files it here, and the site picks it up on the next build. Until then this sample stands in for the real thing.
